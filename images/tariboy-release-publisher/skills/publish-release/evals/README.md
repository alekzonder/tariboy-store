# publish-release skill evals

`evals.json` is the only source in this directory: decisions this skill owns —
version choice, approval boundary, integration, tag publication and recovery.
Whole-image composition and routing belong to `../../../evals/evals.json`.

**REQUIRED:** Use `writing-skills` for the skill text and `authoring-evals`
for the source contract, eval model selection and the matched
baseline/candidate protocol. Generated run evidence belongs in the configured
workdir, not here; accepted verdicts and limitations are published on the
Native Task.
