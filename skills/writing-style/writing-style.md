Before you write any text for a person (a task title, description, comment,
question or answer, a letter or a reply, a `status`, or documentation such as a
README or runbook), read and apply the `writing-style` skill. Write in the
language of the question, or of the document you change. Apply
`simple-english` to English text and `simplified-technical-russian` to Russian
text. Answer first and briefly. Code, commit messages and pull request text are
outside its scope.
